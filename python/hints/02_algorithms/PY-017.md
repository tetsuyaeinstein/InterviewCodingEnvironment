## Hint 1
At any moment the next output is the smallest among the **current head** of each stream. You only ever need K heads in memory. What structure gives you "smallest of K items" in O(log K) and lets you replace the one you removed?

## Hint 2
Store entries that never force Python to compare two raw items: something like `(key, stream_index, ...)`. Since each stream has only one head in the structure at a time, `(key, stream_index)` is already unique, and it encodes the tie rule.

## Hint 3
Make the function a generator. Read the first item of each stream only when the first `next()` happens. After yielding an item from stream `s`, fetch the next item of `s` (and only `s`) before the next comparison. Drop a stream the moment it raises `StopIteration`.
