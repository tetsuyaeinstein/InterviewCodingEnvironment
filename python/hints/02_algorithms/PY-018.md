## Hint 1
You need two things in O(1): finding an entry by key, and knowing which entry is the oldest, with the ability to move an entry to the "newest" end. One structure alone rarely gives both; Python has a dict variant that remembers order and supports moving an item to an end.

## Hint 2
If you build it yourself instead, pair a dict (key to node) with a doubly linked list ordered by recency. Why does the list need to be doubly linked, and why do sentinel head/tail nodes remove most special cases?

## Hint 3
`get` and `put` both "touch" an entry; `__contains__` and `__len__` must not. Validate the capacity in `__init__` (check `bool` explicitly). Evict only when a **new** key pushes the size over capacity, and call the callback with the removed key and value.
