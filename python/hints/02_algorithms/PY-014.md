## Hint 1
Split the job into two phases: count every SKU in one pass over the stream, then rank the (sku, count) pairs. Validate `k` before the first phase.

## Hint 2
The convenient "most common" helper in the standard library breaks ties by first-seen order, which is not the rule here. Write the ranking yourself with one sort key that encodes "count descending, then sku ascending".

## Hint 3
You only need the best k of d candidates. A bounded heap gives O(d log k). Alternatively, counts are integers between 1 and n, so you can group SKUs by count and walk the groups from the highest count down.
