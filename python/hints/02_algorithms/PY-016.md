## Hint 2
Decide the invariant before writing the loop: everything before `lo` is `< target`, everything from `hi` on is `>= target`. Start with `lo = 0`, `hi = len(seq)` (the "not found" answer is a legal position).

## Hint 3
If `seq[mid] < target`, the answer is after `mid`; otherwise `mid` itself might be the answer, so keep it. Stop when `lo == hi`. Which update keeps duplicates from skipping the first one?
