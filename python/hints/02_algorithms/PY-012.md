## Hint 1
Keep a window `[left, right]` that is always valid (all-distinct) and only ever moves forward.

## Hint 2
When the incoming character already exists in the window, where must `left` move to? Can it ever move backwards?

## Hint 3
A dict of "last index where I saw this character" lets you move `left` in one step. Only use it if that index is inside the current window.
