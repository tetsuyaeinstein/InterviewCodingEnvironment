## Hint 1
Unsorted input makes every pair a candidate. Once the windows are ordered by `start`, a window can only merge with the window you are currently building, never with an earlier finished one.

## Hint 2
Keep one "current" window. For the next window, compare its `start` with the current `end`: which comparison (`<` or `<=`) implements "touching windows merge" for half-open windows?

## Hint 3
When merging, the new end is the larger of the two ends (think of a short window nested in a long one). Filter out `start == end` windows and validate `start > end` before anything else.
