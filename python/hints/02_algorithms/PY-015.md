## Hint 1
If you can compute, for each label, a value that is identical for all rearrangements of the same normalised characters and different otherwise, grouping becomes a single dict lookup per label.

## Hint 2
Normalise first (fold the case, remove whitespace), then build that canonical value from the remaining characters. It must keep how many times each character occurs; a plain set of characters does not.

## Hint 3
Two classic canonical values: the sorted characters joined back into a string, or the multiset of character counts in a hashable form. Python dicts keep insertion order, so "groups ordered by first appearance" comes for free if you create each group the first time its key is seen.
