## Hint 1
Count carefully: with `retries=2` there are three attempts but only two sleeps. Decide where in the loop the sleep sits so that it never happens after the final failure.

## Hint 2
Catch only `retry_on` (`except retry_on as exc`), so anything else escapes on its own. Compute the delay as `min(max_delay, base_delay * multiplier ** n)`, or carry a value forward and cap it each iteration, which cannot overflow for large `n`. Jitter is applied to the already-capped value.

## Hint 3
Check the budget *after* you know the delay and *before* sleeping: `clock() + delay > start + budget`. Record `start = clock()` once at the top. Raise the final error with `raise RetryError(...) from exc` so `__cause__` is the last failure. Validate parameters before calling `fn` the first time.
