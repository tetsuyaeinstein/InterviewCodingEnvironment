## Hint 1
Two separate questions per event: (1) which window does it belong to, (2) is that window still open? Answer (1) with integer-style arithmetic on `timedelta` from the epoch (floor division works for pre-1970 dates too). Answer (2) from the watermark.

## Hint 2
Update the maximum event time *first*, derive the watermark from it, and only then decide late-or-not. Keep the open aggregates keyed by window start (then by key); a window is closed once `window_end <= watermark`. The watermark must never decrease, so store the maximum rather than the last event time.

## Hint 3
To emit in a deterministic order without scanning every open window, remember window starts in a min-heap (push when a window is first created) and pop while `start + window <= watermark`; sort each popped window's keys. Track "closed up to" explicitly so that `flush()` can close windows beyond the watermark and later events for them are still late. Convert to UTC once, at the start of `process`.
