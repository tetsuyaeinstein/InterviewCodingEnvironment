## Hint 1
Backpressure is "do not read more until there is room". The simplest way to express room that covers *every* stage (queue, workers, reorder buffer, consumer) is to count items that are in the system with a counting semaphore: take a slot before you pull from the source, give it back only after the consumer is done with that item. Then the bound holds for any number of workers.

## Hint 2
Give every item an index. Workers write `(index, outcome)` into a shared dict guarded by a `Condition`; the thread that calls the consumer waits for index 0, then 1, and so on, which gives ordered delivery for free. Put *failures* into the same dict as outcomes: then "first failure in input order" is just "the first failing index the consumer reaches".

## Hint 3
Never block forever: wait for the semaphore and for the task queue with a short timeout in a loop and check a shared `stop` event each time round, so that every thread notices a failure. In a `finally` set the event and `join()` the threads. A `None` result must not be a sentinel: carry the end of stream as a separate "total number of items" value, set when the source is exhausted (or fails, at index *k*, which then counts as a failed item).
