## Hint 1
Comparing every payload of an id with every other one is quadratic. Instead turn each payload into one canonical, hashable value (for example a string) such that two payloads are "the same" exactly when their canonical values are equal. Then per id you only need a small map from canonical value to (first payload, count).

## Hint 2
Build the canonical value recursively: sort dict items by key, keep list order, and tag every leaf with its type so that `True`, `1` and `"1"` cannot mix. Numbers need one common representation: a normalised `Decimal` text (strip trailing zeros without `Decimal.normalize()`, which rounds beyond 28 digits); turn a float into a `Decimal` through `repr(x)` so that `0.1` matches `Decimal("0.1")`. Handle NaN and infinities separately.

## Hint 3
After one pass, walk the ids in sorted order: one variant with count 1 is unique, one variant with a higher count is an exact duplicate, several variants are a conflict (sum the counts). Python dicts keep insertion order, which gives you first-arrival order of variants for free.
