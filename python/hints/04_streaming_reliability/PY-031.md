## Hint 1
For each key you never need the whole history, only "the highest sequence seen so far" and what was seen *at* that sequence. Compare each new event to that sequence: higher, equal or lower. What does each case do to the state?

## Hint 2
A tombstone is just a winning event whose `op` is `"D"`: keep it in the per-key state and hide it only when building `snapshot()`. Then "a delete blocks older updates" needs no extra code. Per key, store `(top_sequence, list of distinct variants at that sequence)`.

## Hint 3
Decide duplicate vs conflict by comparing the new event against each stored variant with `==` on `(op, payload)` (not on `ingest_ts`; ignore the payload for deletes). On a duplicate, keep the copy with the smaller `ingest_ts`. A higher sequence replaces the whole list, which is what makes a conflict disappear. Build `snapshot()` / `conflicts()` by iterating `sorted(keys)` and copy payloads on the way out.
