## Hint 1
psycopg's `cursor.execute(query, params)` sends the values separately from the SQL text. Placeholders are `%s` (positional) or `%(name)s` (named), never quoted.

## Hint 2
Turn the dates into timezone-aware UTC datetimes at midnight and compare `transaction_ts` against them directly. That gives you a half-open range with no casts on the column.

## Hint 3
An optional filter can live in the SQL itself: `(param IS NULL OR col = ANY(param))`. A Python list adapts to a PostgreSQL array. `psycopg.rows.dict_row` gives you dict rows.
