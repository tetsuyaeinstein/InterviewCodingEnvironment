## Hint 1
Keep a small pending list and flush it when it reaches `batch_size`, plus once at the end if it is not empty. Iterate the source with `enumerate`, so the position is free and nothing is read ahead.

## Hint 2
Put the load call in one helper that handles both modes: it tries the whole batch, and on `Exception` either re-raises (`"raise"`) or falls back to row-by-row loading. The position of each pending row must travel with the row.

## Hint 3
Catch `Exception`, not bare `except:` (so `KeyboardInterrupt` passes through). Format the error as `f"{type(exc).__name__}: {exc}"`. Sort quarantined entries by position at the end, since transform failures and load failures are discovered at different times.
