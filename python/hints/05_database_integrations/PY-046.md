## Hint 1
A generator with a `while True` loop is the natural shape: request a page, yield its items, then look at `next`. Keep a set of ids already yielded and a set of tokens already requested.

## Hint 2
Be careful about the order of operations: yielding the page's items first, then checking the next token for a loop, and only then counting towards the page cap, gives you the "records before the error" behaviour.

## Hint 3
The token for the first page is `None`, so record it as requested too (`None` can go in a set), and do the cap check *before* the request: `pages_requested >= max_pages` while a `next` token is still pending means the error.
