## Hint 1
Write the retry loop as `for attempt in range(max_attempts)`. Decide the wait inside the `except RateLimited` branch; on the last attempt there is nothing to wait for, so just re-raise.

## Hint 2
Take `start = clock()` before the first call. Before sleeping compute `waited = clock() - start`, and give up if `waited + wait > max_total_wait`. Use the number of *rate-limited failures so far* for the exponential backoff.

## Hint 3
For the limiter keep a deque of admission timestamps. On `acquire`: drop timestamps `<= now - period`; if the deque is shorter than `max_calls`, admit; otherwise sleep `oldest + period - now` and loop again (recompute `now` from the clock).
