## Hint 1
`asyncio.Semaphore(limit)` around each unit of work caps concurrency. Alternatively start exactly `limit` worker tasks that all pull the next item from one shared iterator, so the cap is structural rather than enforced by a lock.

## Hint 2
Keep the original index with each item and store results by index; then rebuild the list in input order. For fail-fast, remember the first exception in time, then cancel the other tasks.

## Hint 3
Cancelling is not enough: `task.cancel()` only requests it. Await the cancelled tasks (`await asyncio.gather(*tasks, return_exceptions=True)`) so their `finally` blocks run before you raise. Do the cleanup in a `finally` so outer cancellation takes the same path.
