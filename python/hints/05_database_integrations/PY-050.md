## Hint 1
Split the job into small pure steps you can reason about separately: `parse_line -> row or reason`, `dedupe(rows) -> winners`, `summarise(winners)`, then the database part. Only the last step needs the connection.

## Hint 2
`json.loads(line, parse_float=Decimal)` keeps JSON numbers exact. For timestamps `datetime.fromisoformat` handles offsets and `Z` (Python 3.11+); check `tzinfo` afterwards. For the database: `CREATE TABLE IF NOT EXISTS stg_txn (...)` without a schema, then one `INSERT ... SELECT ... FROM unnest(...) ON CONFLICT (transaction_id) DO UPDATE ... WHERE stg_txn.sequence < EXCLUDED.sequence RETURNING ...` per batch.

## Hint 3
Wrap everything (create, upserts, the reconciliation query) in `conn.transaction()` so any exception, including your own `ReconciliationError`, undoes the whole run. Do the reconciliation with a SQL aggregate over only this run's ids and compare it to the Python dict with `==`.
