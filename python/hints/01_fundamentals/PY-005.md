## Hint 1
Validate the *shape* yourself before trusting a library parser: `datetime.fromisoformat` in Python 3.11+ happily accepts a date-only string and returns midnight. Decide naive vs aware from the presence of a designator.

## Hint 2
For a naive wall time in a `ZoneInfo` zone, build it twice, with `fold=0` and `fold=1`. If both give the same `utcoffset()`, the time is unambiguous.

## Hint 3
If the two offsets differ, the time is either in a gap or in an overlap. Convert the `fold=0` version to UTC and back to the zone: if the wall-clock time changed, it never existed.
