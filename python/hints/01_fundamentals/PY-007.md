## Hint 1
Split the work into three layers: validate the schema (may raise), validate one value against one `FieldSpec` (returns either a coerced value or an error code + message, never raises), and a row loop that collects results.

## Hint 2
Have the per-type coercers signal failure by raising a small private exception carrying the error code, and catch it in the row loop. That keeps each coercer short and guarantees "one error per field". Order your `isinstance` checks: `bool` before `int`, `datetime` before `date`.

## Hint 3
Process the schema first, then the unknown keys (`sorted(..., key=str)` for the error policy). A row is valid only if the error list didn't grow while processing it. Build each output row as a fresh dict.
