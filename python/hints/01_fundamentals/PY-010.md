## Hint 1
A function containing `yield` runs *none* of its body until the first `next()`, so its argument checks are lazy too. Split the work: an ordinary function that validates, and an inner generator that it returns.

## Hint 2
Call `iter()` on the input once, up front, and keep using that same iterator. Calling `iter()` again on a list restarts it; on a generator it does not.

## Hint 3
`itertools.islice(it, size)` takes at most `size` items from an iterator and no more. Stop when it gives you an empty list.
