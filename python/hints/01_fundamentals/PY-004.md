## Hint 1
Write a tiny helper that turns any container into `(segment, value)` pairs: keys for mappings, `str(index)` for lists/tuples. Then the walk doesn't care which kind of container it is in.

## Hint 2
Recursion is the natural first draft, but the default recursion limit is about 1,000 frames. Replace the call stack with your own list of `(prefix, depth, iterator)` frames. Keeping an *iterator* per frame preserves the input's order.

## Hint 3
Every write into the output goes through one function that checks "is this key already present?" and deep-copies container values. Decide "expand or emit?" from three facts: is it a container, is it non-empty, and is the depth below `max_depth`?
