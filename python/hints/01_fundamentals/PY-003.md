## Hint 1
Validate `k` first (type, then sign). `isinstance(True, int)` is true, so check `bool` explicitly.

## Hint 2
A single sort key can express both rules at once: what can you negate so that "descending spend, ascending id" becomes plain ascending order?

## Hint 3
`heapq` has functions that keep only the best k items while scanning, so you never sort all n. They accept the same kind of key function as `sorted`.
