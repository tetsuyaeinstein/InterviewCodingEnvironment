## Hint 1
You only need to remember which ids you have already emitted, not the records themselves.

## Hint 2
Checking "have I seen this id?" must be O(1). Which built-in container gives you that? A list does not.

## Hint 3
Treat "key missing" and "value is None" the same way, and decide that before the seen-check: those records bypass it entirely.
