## Hint 1
The partition is the calendar date *in the target zone*, so the timestamp must be converted with `astimezone(...)` before you read `.year/.month/.day`. Using the date as written in the source string uses the sender's zone.

## Hint 2
`zoneinfo.ZoneInfo(name)` turns a zone name into a `tzinfo`. Check `tzinfo is None` (or `utcoffset() is None`) and raise instead of attaching UTC to naive values.

## Hint 3
Build the key with an f-string and format specs like `{year:04d}`. Join with `"/"` yourself rather than `os.path.join`. Group with `dict.setdefault(key, []).append(rec)`, then rebuild the dict in `sorted()` key order.
