## Hint 1
Separate the three questions for every field: is it NULL (absent, `None`, or a null token after stripping)? If so, is NULL allowed? If not NULL, which parser handles this column's kind? Pick the parser per column once, then loop over rows.

## Hint 2
Write each accepted grammar as an anchored pattern (`re.fullmatch`) over `[0-9]`, not `\d`, and only then convert. Converting first (`Decimal(text.replace(",", ""))`, `strptime`, `date.fromisoformat`) accepts spellings the contract rejects, such as misplaced commas, unpadded or compact dates, and exponents.

## Hint 3
For slash dates, map `(A, B)` to `(month, day)` from `slash_date_order` and let `date(y, m, d)` reject impossible dates. Do not try the other order on failure. For timestamps, `fromisoformat` then check `tzinfo`/`utcoffset()` before `astimezone(timezone.utc)`. Accounting negatives: strip the parentheses, prefix `-`, remove the commas, then build the `Decimal` from that string so its scale is kept.
