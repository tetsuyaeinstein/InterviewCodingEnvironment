## Hint 1
For each key you only ever need what happened at the *highest sequence so far*. When a record arrives, there are exactly three cases relative to that sequence: higher, equal, lower. What does each one do to your per-key state?

## Hint 2
The state per key can be "best sequence + the list of distinct payloads seen at that sequence". Equality is checked with `==` against that (normally tiny) list, after removing the ignored fields, so unhashable nested values are fine. Keep the full original record next to each payload for the output.

## Hint 3
Only decide winner-vs-conflict at the end: one distinct payload → current record; more → `Conflict`. Iterate `sorted(state)` so both outputs are ordered by key regardless of arrival order. Convert digit strings with `int()` before comparing, and reject `bool` explicitly (it is an `int` subclass).
