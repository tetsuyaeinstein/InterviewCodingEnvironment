## Hint 1
Splitting lines on `","` cannot handle quoted commas or newlines inside a field. Let the standard library's CSV reader do the tokenising. It accepts any iterable of lines, and a path needs to be opened in a way that does not translate the newlines the reader must see. Which encoding name makes the BOM disappear for you?

## Hint 2
Read the header first and turn it into a column-name -> position mapping that you validate (missing, duplicated). Then iterate the remaining rows one at a time. Never build a list of rows, and do not call anything that reads the whole input.

## Hint 3
Filter on status *before* touching the amount. `Decimal("NaN")` is a valid `Decimal`, so check that the parsed value is finite. Accumulate into a plain dict with `dict.get(key, Decimal(0)) + amount`, and remember that an empty customer id means "guest", not a customer called `""`.
