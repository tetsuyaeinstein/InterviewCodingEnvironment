## Hint 1
Separate *canonicalisation* from *encoding*. First map each row to a dict `{field: (type_tag, canonical_text)}` that drops NULLs and excluded fields, renders numbers from a normalised `Decimal` (watch out for zero), and tags booleans and strings differently. Comparing two such dicts with `==` already gives you "changed" and which fields differ.

## Hint 2
The encoding fed to SHA-256 must be injective. Either escape everything (e.g. `json.dumps` of a sorted list of `[name, tag, text]` triples) or length-prefix every token (`b"%d:" % len(part) + part`). Plain delimiters are not enough, because a value can contain the delimiter.

## Hint 3
For the diff, build `key -> (hash, canonical dict)` for one side, then stream the other side: pop the key, compare hashes, and compute the differing fields only on a mismatch. Whatever is left in the map is "extra". Alternatively, sort both sides by key and walk them together like a merge join. Either way, detect duplicate keys and sort the report lists.
