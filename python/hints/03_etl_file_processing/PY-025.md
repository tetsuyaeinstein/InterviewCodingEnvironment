## Hint 1
Keep one small accumulator per column and update it per value. `count` is the same for every column (total rows), so `null_count = rows - non_null_seen`. That also takes care of columns that appear late.

## Hint 2
Classify each value into a type name in the right order (`bool` before `int`, `datetime` before `date`). Use a "family" (numeric / bool / str / date / datetime) as part of the identity key for distinct counting: `(family, value)` makes `1 == Decimal("1.00")` but keeps `True` and `1` apart. A dict from that key to `[first_value, count]` gives you distinct, top-k and representatives at once.

## Hint 3
Track min/max per family, so you never compare across incomparable types mid-stream, and only report them at the end if the column is not mixed. Keep an exact `Decimal` running sum for numerics. For top-3, a stable sort by `-count` over insertion-ordered entries breaks ties by first occurrence.
