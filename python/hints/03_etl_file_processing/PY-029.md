## Hint 1
Two phases. Phase 1: fill a buffer up to M rows, `list.sort(key=...)` it (stable), write it with `csv.writer` to a `tempfile.mkstemp(dir=work_dir)` file, notify the callback, and clear the buffer. Don't forget the last partial buffer. Phase 2: open one `csv.reader` per run and merge them.

## Hint 2
`heapq.merge(*iterables, key=...)` lazily yields the smallest head among k sorted iterables. When keys tie it prefers the earlier iterable, so if runs are passed in creation order the whole sort stays stable. `contextlib.ExitStack` lets you open k files and guarantee they are all closed.

## Hint 3
Record each run path in a list *before* writing it, and delete them all in a `finally:` after every file handle is closed (Windows). Write the merged output to a temp file next to `dest` and `os.replace` it at the end, so a failure never leaves a partial `dest`.
