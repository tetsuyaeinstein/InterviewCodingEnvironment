## Hint 1
Make the function a generator: `for line_number, line in enumerate(lines, start=1)`. Number every physical line *before* deciding to skip it, and keep the original text (minus the terminator) for the quarantine entry.

## Hint 2
`json.loads` is too forgiving for this contract in two ways: it accepts `NaN`/`Infinity`, and it silently keeps the last of duplicated keys. Look at the keyword arguments of `json.JSONDecoder` / `json.loads`: there are hooks for pairs, for floats and for constants.

## Hint 3
Classify in order: blank → decode (catch `ValueError`, which covers `JSONDecodeError`, and also catch the error that deep nesting raises) → `isinstance(obj, dict)` → missing required keys → yield. Strip a leading `﻿` only when `line_number == 1`.
