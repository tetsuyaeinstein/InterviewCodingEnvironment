## Hint 1
The atomic step is a rename on the same volume, so the new content must be complete in a *different* file in `dest`'s directory first. `tempfile.mkstemp(dir=...)` or `NamedTemporaryFile(dir=..., delete=False)` gives you a unique name there.

## Hint 2
Order matters: write all lines → `flush()` → `os.fsync(fileno)` → close → `os.replace(tmp, dest)`. On Windows both the temp file and the source must be closed before the replace. Open the output with `newline="\n"` so `"\n"` is not translated to `"\r\n"`.

## Hint 3
Wrap everything after the temp file is created in `try: ... except BaseException: remove temp; raise`. Catching only `Exception` misses Ctrl+C. Make sure the temp file is closed before you remove it, and don't swallow or replace the original exception.
