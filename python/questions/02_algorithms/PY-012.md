# PY-012 · Longest window of distinct status codes

**Topic:** algorithms & interview patterns · **Level:** medium · **Interview time:** ~15 min · **Module:** `python/practice/02_algorithms/PY-012.py`

## Scenario

Each kiosk emits a stream of one-character status codes, for example `"AABCDAB"`. Operations wants
the **longest contiguous stretch in which no code repeats**. They use it as a quick measure of
"healthy variety" in a diagnostic trace. Traces can be very long, so the approach must be linear.

## Function contract

```text
longest_unique_substring(s: str) -> str
```

- Return the longest **contiguous** substring of `s` in which every character is distinct.
- If several substrings share the maximum length, return the one that **starts first**.
- Characters are compared exactly. Matching is case-sensitive, and spaces, punctuation and
  non-ASCII characters are ordinary characters.
- Return `""` for an empty input.
- Do not mutate global state. The function must be pure.

## Examples

| input | output |
|---|---|
| `"abcabcbb"` | `"abc"` |
| `"bbbbb"` | `"b"` |
| `"pwwkew"` | `"wke"` |
| `"abba"` | `"ab"` |
| `"xyzxyz"` | `"xyz"` (first of several equal-length answers) |
| `""` | `""` |

## Corner cases to think about

- A repeat whose previous occurrence is **outside** the current window (e.g. `"abba"`, `"tmmzuxt"`).
- An empty string and a single character.
- Ties between equal-length windows.
- A very large alphabet (any Unicode characters), not just `a-z`.

## Expected complexity

- Time **O(n)** for an input of length n. The tests include a 40,000-character input with a
  20,000-symbol alphabet, which a quadratic approach will not finish in time.
- Extra space O(min(n, alphabet size)).
