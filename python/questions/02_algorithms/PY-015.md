# PY-015 · Group scrambled product labels

**Topic:** algorithms & interview patterns · **Level:** easy · **Interview time:** ~10 min · **Module:** `python/practice/02_algorithms/PY-015.py`

## Scenario

A supplier's feed contains product labels whose characters were sometimes **scrambled** by a buggy
export: `"TEA BAG"`, `"tae gab"` and `"Bag Eat"` are all the same characters in a different order.
Before deduplicating, the data-quality team wants these labels **grouped**: two labels belong to the
same group when one is a rearrangement of the other's characters, under the normalisation below.

## Function contract

```text
group_anagram_labels(labels: Iterable[str]) -> list[list[str]]
```

Normalisation used **only for comparing** labels:

- **Case is ignored**, using full Unicode case folding (`str.casefold`). So `"ß"` compares like
  `"ss"`.
- **All whitespace is ignored** (spaces, tabs, newlines, anywhere in the label).
- Every other character counts: digits, punctuation, hyphens, accents. `"A-1"` and `"1-a"` match,
  `"A1"` and `"A-1"` do not.
- Character **multiplicity** matters: `"aab"` and `"abb"` are different.

Output:

- A list of groups. Each group is a list of the **original** labels (unchanged spelling).
- Groups are ordered by the position of their **first** label in the input.
- Inside a group, labels keep their **input order**.
- **Duplicates are kept**: a label that appears twice appears twice in its group.
- A label that is empty after normalisation (`""`, `"   "`) is grouped with the other empty ones.
- Empty input returns `[]`. The input may be any iterable (read once). Do not mutate it.

## Example

`["TEA BAG", "lamp", "tae gab", "palm", "Bag Eat", "LAMP", "tea bag", "teabags"]`

returns

```text
[["TEA BAG", "tae gab", "Bag Eat", "tea bag"],
 ["lamp", "palm", "LAMP"],
 ["teabags"]]
```

## Corner cases to think about

- Same letters, different counts (`"aab"` vs `"abb"`).
- Labels that differ only in case or spacing.
- Exact duplicate labels.
- Punctuation and digits.
- Non-ASCII characters and case folding.

## Expected complexity

About O(n · L log L) or O(n · L) for n labels of length up to L, with one dict lookup per label.
Comparing every pair of labels (O(n²)) is too slow for a feed of 100,000 labels.

## Clarify before you code

- Is the comparison case-sensitive? Do spaces count? (No and no.)
- Should the output be sorted alphabetically, or keep the feed order? (Feed order.)
- Do exact duplicates collapse? (No: dedup is the next step, not this one.)
