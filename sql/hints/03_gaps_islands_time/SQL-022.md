## Hint 1
Fix the grain before anything else: one row per customer per UTC purchase day. Streak boundaries are then just the first and last day of each run.

## Hint 2
If you number each customer's distinct purchase days 1, 2, 3, ... in date order, the value `purchase_date - number` is the same for every day of one run and changes when a day is skipped.

## Hint 3
Group by (customer, that derived key): `MIN` is the start, `MAX` is the end, `COUNT(*)` is the length. Keep groups with at least 3 rows. Check that you de-duplicated days before numbering them.
