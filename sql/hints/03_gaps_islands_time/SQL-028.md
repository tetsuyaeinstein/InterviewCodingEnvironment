## Hint 1
Each line needs the one price version whose interval contains its timestamp. Write that condition down precisely, including the open-ended current version and what happens at the exact change instant.

## Hint 2
Half-open means `valid_from <= ts AND ts < valid_to`. A version with `valid_to IS NULL` contains every later instant. `BETWEEN` is inclusive on both sides and matches two versions at a change instant.

## Hint 3
Use an outer join from the lines to the price history with the interval condition in the `ON` clause (not in `WHERE`), so lines without history survive with NULLs. Alternatively, per line pick the latest version with `valid_from <= ts`.
