## Hint 1
Look at each event together with the customer's previous event. The only thing that decides whether a new session starts is the gap between those two timestamps.

## Hint 2
Mark each event with 1 if it starts a session (no previous event, or gap strictly greater than `interval '30 minutes'`) and 0 otherwise. Make the ordering total so equal timestamps are handled deterministically.

## Hint 3
A running sum of those markers per customer, in the same order, is the session number. Group by (customer, session number) for start, end and count.
