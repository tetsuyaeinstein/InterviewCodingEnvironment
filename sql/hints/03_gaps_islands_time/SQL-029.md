## Hint 1
Think of the result as a small grid: every in-scope transaction times every selected product. Each cell is "available" or "not available" at that transaction's instant.

## Hint 2
Fill each cell by outer-joining the availability version that covers the timestamp (half-open). No covering version must end up as "not available", not as NULL that silently disappears from an aggregate.

## Hint 3
Aggregate per transaction: `BOOL_AND` for all, `BOOL_OR` for any, `COUNT(*) FILTER (WHERE ...)` for the number. A different technique is relational division: ALL holds when there is no selected product for which no available version covers the instant (`NOT EXISTS ... NOT EXISTS`).
