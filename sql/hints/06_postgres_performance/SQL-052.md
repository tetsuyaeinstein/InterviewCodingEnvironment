## Hint 1
An index on `transaction_ts` stores the column's values in order. It can only find rows whose predicate is "column compared with something constant". Is `transaction_ts::date = ...` such a predicate?

## Hint 2
"The UTC calendar day 2025-02-28" is the same thing as "every instant from the start of that day up to, but not including, the start of the next day".

## Hint 3
Two comparisons on the bare column: `>=` the first instant of the day, and `<` the first instant of the following day. Write the bounds as `timestamptz` literals with an explicit `+00` offset so they don't depend on the session time zone.
