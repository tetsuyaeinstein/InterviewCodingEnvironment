## Hint 1
Try to add the unique constraint first and read the error. The order of the three steps is dictated by what the database refuses.

## Hint 2
To delete all but one copy of a row you need a way to tell copies apart. Number the rows within each `message_id` in delivery order, and use the physical row address (`ctid`) as the identifier to delete by. Or avoid deleting: build the clean set with `DISTINCT ON` and replace the table.

## Hint 3
`ON CONFLICT DO NOTHING` skips a row **when it meets an existing one** in the order the rows are inserted. If the batch holds the same message twice, which one is "first" is decided by the order of the `SELECT` feeding the INSERT, so make that order explicit.
