## Hint 1
Run the query before creating any index and read the plan: where does the time go, and is there a Sort node above the scan?

## Hint 2
An index is a list sorted by its first column, then by the second within equal firsts, and so on. Which column must be fixed to a single value for the remaining column to come out already sorted?

## Hint 3
Put the equality column first and the range/ORDER BY column second. Then compare with the reverse order: with the time column first, the rows come out in time order but the customer is no longer a search condition. Look at the `Index Cond` line to see which columns the index actually searched.
