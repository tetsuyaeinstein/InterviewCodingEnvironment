## Hint 1
Look at the JSON type of each key before you cast anything: `jsonb_typeof()` tells number, string, boolean, null and missing (SQL NULL) apart. Extract text with `->>` and keep `->` for the typed JSON value.

## Hint 2
A `CASE` expression only evaluates the branch it enters. Put the cast inside a branch that is reached only when the text is known to be valid. PostgreSQL 16+ has a function that answers "would this text be accepted as type X?" without raising an error.

## Hint 3
For the member flag, do not cast text to boolean: PostgreSQL's boolean input also accepts words you must reject. Compare against the exact accepted values instead. Finally wrap the issue flag so a NULL comparison cannot leak a NULL into the boolean column.
