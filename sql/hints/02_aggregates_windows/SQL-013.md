## Hint 1
The transactions table cannot produce rows for days on which nothing happened. You need a source of calendar days per store, then attach the daily revenue to it (zero when missing).

## Hint 2
A frame of "the current row and the 6 rows before it" only means "7 calendar days" when there is exactly one row per calendar day with no gaps. Either make the days dense first, or use a frame defined by a date distance rather than a row count.

## Hint 3
Build the dense calendar from 6 days before the first report date to the last report date (`generate_series`), left join daily revenue with `COALESCE(..., 0)`, run a 7-row trailing sum partitioned by store, and only then filter to the report period in an outer query.
