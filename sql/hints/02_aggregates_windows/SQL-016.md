## Hint 1
Start from `customers`, not from `transactions`, so that every customer survives. Where does the status condition have to go so that it does not turn your outer join back into an inner join?

## Hint 2
Aggregate the completed transactions per customer (earliest, latest, count) in a separate step, then attach the result to the customer list. Count something that is NULL for non-buyers, or use `COALESCE`.

## Hint 3
Convert both timestamps to UTC dates first and subtract the dates: `date - date` is an integer number of calendar days in PostgreSQL. Subtracting timestamps gives an interval of elapsed time, which is not the same thing.
