## Hint 1
Get to the output grain first: one row per customer per UTC date, with that day's completed spend. Only then compute the cumulative figure.

## Hint 2
The cumulative figure is a sum over "all earlier rows of the same customer, plus this one". Think about what defines the group and what defines "earlier".

## Hint 3
`SUM(daily_spend) OVER (PARTITION BY customer_id ORDER BY purchase_date ...)` on the daily rows. If you instead run it on transaction rows, two transactions on one day give two rows with different partial totals.
