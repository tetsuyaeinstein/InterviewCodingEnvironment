## Hint 1
Which column holds revenue at the grain you need? The header's `gross_amount` is per basket; once you join it to lines, every basket amount repeats once per line. Build revenue from the line columns instead.

## Hint 2
Aggregate to one row per (region, product) first. Both the rank and the region total are then computations over the rows of the same region, and both must be computed before you discard anything.

## Hint 3
On the (region, product) rows compute `RANK() OVER (PARTITION BY region ORDER BY net_revenue DESC)` and `SUM(net_revenue) OVER (PARTITION BY region)` in the same query level, then filter `rank <= 3` in an outer query. A filter at the same level would shrink the total.
