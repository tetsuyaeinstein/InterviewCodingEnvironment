## Hint 1
Start from a grid of days × products so empty days still produce a row. Then ask, for each cell,
which history rows touch that day.

## Hint 2
A half-open row `[from, to)` touches the day `[start, end)` when `from < end` and `to > start`
(treat a NULL `to` as infinity). "Status at the end of the day" is the row that contains the instant
`end - 1 microsecond`.

## Hint 3
Minutes available = the sum of the intersection lengths: later of the starts to earlier of the ends,
only for rows with `available = true`. Uncovered time contributes nothing, which is why the boolean
aggregates need a default of false for cells with no matching row.
