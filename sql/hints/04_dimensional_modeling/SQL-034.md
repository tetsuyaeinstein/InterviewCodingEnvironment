## Hint 1
Postings only exist on days when something happened, but the output needs every account × day.
Build that grid first (accounts in scope × a generated series of dates), then attach the
ledger to it.

## Hint 2
The closing balance is a running total: start from the balance before the window, then add each
day's net change in date order. Days without postings add 0, which is what carries the balance
forward. Treat the window bounds as UTC midnights and keep every comparison half-open.

## Hint 3
For the intraday low, compute a running balance per posting (ordered by `posting_ts`, then
`entry_id`), take its minimum per account-day, and compare it with the start-of-day balance, which
is `closing_balance - net_change`. `LEAST` ignores NULLs, so days without postings fall back to
the start-of-day value.
