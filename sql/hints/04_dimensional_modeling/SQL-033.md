## Hint 1
Split the problem in two: first find the sales for which **no** containing version exists, then
describe where each of those sales sits relative to the customer's versions.

## Hint 2
"No containing version" is a NOT EXISTS (or an outer join that found nothing) with the half-open
condition `effective_from <= ts AND ts < effective_to`. Once a sale has no containing version,
every version of that customer either ended at or before the sale, or starts after it.

## Hint 3
For the unmatched sales, aggregate the customer's versions with two filtered aggregates: the
largest `effective_to` that is `<= ts`, and the smallest `effective_from` that is `> ts`. Which
of the two is NULL decides the reason. Use an outer join here so a customer without versions still
produces a row.
