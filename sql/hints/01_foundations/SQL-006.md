## Hint 1
One pass over the 2025 rows, grouped by store. Each output column is an aggregate restricted to one status.

## Hint 2
PostgreSQL supports `aggregate(...) FILTER (WHERE ...)`; the portable spelling is `SUM(CASE WHEN ... THEN amount END)`.

## Hint 3
A count over no matching rows is 0, but a sum over no matching rows is NULL. Make the empty sums 0.00, and leave declined rows out of every amount (they still count in the total).
