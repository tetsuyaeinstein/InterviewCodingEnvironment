## Hint 1
Start from `customers` so every customer, and therefore every segment, is present. The transaction conditions belong to the outer join condition, not the `WHERE` clause.

## Hint 2
`AVG(gross_amount)` over an outer join averages only the matched rows, which is right for the transaction average, but `COUNT(*)` counts non-buyers as one row each. Count transaction ids instead, and count non-buyers explicitly.

## Hint 3
Compute the averages yourself from totals: amount / transactions (wrap the denominator in `NULLIF(..., 0)` to get NULL instead of a division error) and amount / customers. Averaging per-customer averages answers a different question.
