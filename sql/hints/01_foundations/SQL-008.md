## Hint 1
First produce one row per category with gross, discount and net revenue for the scoped lines. Make sure the status filter is applied before anything is summed.

## Hint 2
`LIMIT 2` cuts ties arbitrarily, and a rank that skips positions (1, 1, 3) would keep only the first level. You need a rank where tied values share a number and the next value gets the next integer.

## Hint 3
Compute both ranks over the same ordering (`net_revenue DESC`), filter in an outer query (a window function cannot be used in `WHERE` of the same level), and finish with an explicit `ORDER BY net_revenue DESC, category_name`.
