## Hint 1
Define one set of in-scope purchase lines (completed, known customer, in period, product A or B). Both the A test and the B test must use exactly this set.

## Hint 2
"Never bought B" is an absence test. `NOT IN (subquery)` returns no rows at all if the subquery yields a single NULL, and guest checkouts have a NULL customer. `NOT EXISTS`, an outer anti-join or `EXCEPT` are NULL-safe alternatives.

## Hint 3
Alternatively, group the in-scope lines by customer and keep groups where "some line is A" is true and "some line is B" is false (for example `BOOL_OR`, or comparing filtered counts with 0).
