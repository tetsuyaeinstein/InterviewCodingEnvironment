## Hint 1
Three identifiers, three grains: `delivery_id` (a physical delivery), `message_id` (a logical message), `transaction_id` (the business key). Every metric in the contract counts one of these, so decide for each column whether it counts rows or **distinct** message ids.

## Hint 2
A redelivered CREATED message is still one CREATED **message**. Count distinct message ids per event type with a filtered aggregate; `has_redelivery` falls out of comparing deliveries with distinct messages.

## Hint 3
For the conflict test compare only CREATED payloads: a STATUS_CHANGED payload legitimately differs. jsonb values can be compared and counted with DISTINCT directly. Then apply the precedence with a `CASE` whose branches are ordered from most to least severe.
