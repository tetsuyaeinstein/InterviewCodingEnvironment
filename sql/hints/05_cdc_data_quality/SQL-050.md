## Hint 1
`MAX(window_end)` of successful runs is the bug you are investigating: it jumps over holes. You need the end of the *contiguous* run of covered time starting at the history start.

## Hint 2
Sort each source's successful windows by start, and carry the maximum end seen so far (a window function over the preceding rows). A window that starts after that running maximum begins a new island: there is a hole before it.

## Hint 3
The safe watermark is the largest end within the first island, provided that island starts at the history start. Alternatively, walk forward with a recursive CTE: from the current position, jump to the end of a successful run that starts exactly there. For the status column, look up the latest attempt of the window that starts at the safe watermark.
