## Hint 1
Treat each issue type as its own small query that returns `(cdc_event_id, priority, issue_type, related_event_id)`. Combine them with `UNION ALL` and pick the best priority per event at the end.

## Hint 2
Most definitions compare an event with *other events of the same key*. A self-join on the full key, with the right extra predicate (same LSN and different version; earlier arrival and higher LSN; ...), plus `MIN(other.cdc_event_id)` grouped by the event, gives you the related event directly.

## Hint 3
"Arrived earlier" is `other.cdc_event_id < e.cdc_event_id`. Version equality is `(operation, payload)`, and `IS DISTINCT FROM` works on row values. For the orphan rule, use `NOT EXISTS` an insert with a lower LSN. Finish with `DISTINCT ON (cdc_event_id) ... ORDER BY cdc_event_id, priority`.
