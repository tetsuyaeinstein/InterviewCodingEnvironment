## Hint 1
Reduce the batch to one winning event per key first, exactly as in SQL-041. Everything after that is about one row per key.

## Hint 2
"Newer than everything known" needs both the live row and the tombstone: left-join both and compare the winner's LSN with the larger of the two (`GREATEST` ignores NULLs). Compute this filtered set **before** you modify either table, or materialise it.

## Hint 3
Split the filtered set by operation. Deletes remove live rows and upsert tombstones (`ON CONFLICT ... DO UPDATE`). Inserts and updates upsert live rows and delete tombstones. `MERGE ... WHEN MATCHED AND op = 'D' THEN DELETE` handles one table per statement.
