## Hint 1
Hashing is the easy part. The hard part is building a text encoding of the eight columns that is *injective*: different rows must never produce the same string. Try `concat_ws('|', ...)` on fixtures 90017/90018 in your head, and remember what `concat_ws` does with NULLs.

## Hint 2
There are two classic ways to make an encoding unambiguous: escape/quote each value so the delimiter can't appear inside it (and give NULL its own marker), or prefix each value with its length. A JSON array of the values does the quoting for you.

## Hint 3
Pin the formatting of non-text types: render `transaction_ts` in UTC with an explicit format and keep `amount` at its declared scale. Then hash: `md5(text)` returns hex, while `sha256()` takes `bytea`, so use `encode(sha256(convert_to(text, 'UTF8')), 'hex')`. Stack both tables with `UNION ALL`.
